Course description:
Observes supervised and unsupervised learning approaches to chemical processes
Process data first, then including physics data to make physics-informed CNNs
Physics-informed CNNs (PINNs) will typically use our own data. You can add a loss function to the training of the CNN that penalizes the model for violating physical laws. For example, if you have a CNN that is predicting the temperature distribution in a chemical reactor, you can add a loss term that penalizes the model for predicting temperatures that violate the conservation of energy. This way, the model will learn to make predictions that are consistent with physical principles, even if it is trained on limited data.
