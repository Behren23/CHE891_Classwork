4.3 Optimizing $k$ — Elbow and Silhouette¶

Fit K-means for a range of $k$ and plot:

  • WCSS (within-cluster sum of squares) — look for the elbow
  • Silhouette score — higher is better; a peak suggests optimal $k$

Then go back and update k in section 4.1 if needed.

In [39]:
k_range = range(2, 11)
wcss = []  
sil  = []  

for k in k_range:
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = km.fit_predict(X_scaled)
    wcss.append(km.inertia_)  # <- you  hint: km.inertia_
    sil.append(silhouette_score(X_scaled,labels))   # <- you  hint: silhouette_score()

5B. Hierarchical Clustering (Date-Stratified Subsample)¶

Repeat cells 22–26, but build the dendrogram from a subsample stratified over time so all periods are represented.

In [58]:
rng = np.random.default_rng(42)

# Convert to datetime and create 10 chronological bins (deciles in time).
dates_dt = pd.to_datetime(dates)
time_bins = pd.qcut(dates_dt.rank(method='first'), q=10, labels=False)

# Stratified sample size target (same size as the random-subsample dendrogram).
n_sub = 500

# Sample roughly equal counts from each time bin so the full date span is represented.
idx_strat = []
for b in np.sort(np.unique(time_bins)):
    idx_bin = np.where(time_bins == b)[0]
    take = min(len(idx_bin), int(np.ceil(n_sub / len(np.unique(time_bins)))))
    idx_strat.extend(rng.choice(idx_bin, size=take, replace=False))

# Trim to exactly n_sub points if we overshoot.
idx_strat = np.array(idx_strat[:n_sub])
X_sub_strat = X_scaled[idx_strat]

# Ward-linkage dendrogram on date-stratified subsample.
Z_strat = linkage(X_sub_strat, method='ward')

fig, ax = subplots(figsize=(12, 4))
dendrogram(Z_strat, ax=ax, truncate_mode='lastp', p=30,
           leaf_rotation=90, leaf_font_size=8,
           show_contracted=True)
ax.set_title('Hierarchical dendrogram (500-sample date-stratified subset, Ward linkage)')
ax.set_xlabel('Sample index / cluster size')
ax.set_ylabel('Distance')
tight_layout()
show()

6. Column Clustering — Grouping Sensors¶

Clustering the features (columns) rather than samples reveals which sensors move together — useful for understanding process topology and for variable selection. The correlation matrix is a natural distance metric for this.

In [65]:
import seaborn as sns

dfX_scaled = pd.DataFrame(
    X_scaled,
    columns=df.loc[:, 'x1:Primary Column Reflux Flow':'x40: Feed Column Tails Flow'].columns,
)

# Sensor-to-sensor correlation matrix (features clustered, not samples).
corr = dfX_scaled.corr()
short_X_names = [c.split(':')[0] for c in corr.columns]

# Build a feature linkage tree and cut it into the user-selected number of clusters.
# This makes the correlation plot explicitly respect `n_clusters`.
Z_feat = linkage(dfX_scaled.T, method='ward')
feature_cluster_ids = fcluster(Z_feat, t=n_clusters, criterion='maxclust')

# Color bars to show cluster membership for each sensor on both axes.
palette = sns.color_palette('tab10', n_colors=n_clusters)
feature_colors = [palette[cid - 1] for cid in feature_cluster_ids]
row_col_colors = pd.Series(feature_colors, index=corr.index)

g = sns.clustermap(
    corr,
    cmap='RdBu_r',
    vmin=-1,
    vmax=1,
    xticklabels=short_X_names,
    yticklabels=short_X_names,
    figsize=(10, 10),
    row_linkage=Z_feat,
    col_linkage=Z_feat,
    row_colors=row_col_colors,
    col_colors=row_col_colors,
    linewidths=0,
)
g.fig.suptitle(f'Sensor correlation — clustered (n_clusters={n_clusters})', y=1.01)
g.ax_heatmap.tick_params(labelsize=7)
show()
