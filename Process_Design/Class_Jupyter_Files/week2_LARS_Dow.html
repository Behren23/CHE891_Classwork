Dow Data Challenge: LARS Regression¶

CHE 891 — Week 2¶

We apply Least Angle Regression (LARS) to the Dow impurity dataset. LARS is well-suited here because:

  • The 42 process variables are strongly collinear
  • We want a sparse model — only the most relevant sensors
  • LARS produces the full regularization path at the cost of one OLS fit

3. Pipe and Model¶

We use a Pipeline (scaling inside) and TransformedTargetRegressor (softplus transform on $y$).

The softplus inverse $z = \ln(e^y - 1)$ maps positive $y$ to the real line before fitting. Predictions are automatically inverse-transformed back via softplus $y = \ln(1 + e^z)$.

In [4]:
def softplus(z):
    return np.logaddexp(z, 0)       # log(1 + exp(z)), numerically stable

def softplus_inv(y):
    return np.log(np.expm1(y))      # log(exp(y) - 1), valid for y > 0

pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('lars',   Lars(n_nonzero_coefs=len(feat_cols)))
])

model = TransformedTargetRegressor(
    regressor=pipe,
    func=softplus_inv,      # y → z for training
    inverse_func=softplus   # z → y for prediction
)
model.fit(X_train, y_train)
print("Model fitted.")

Model fitted.

4. LARS Path¶

lars_path computes the full regularization path directly on scaled $X$ and transformed $y$. It returns (alphas, active, coefs) where coefs has shape (n_features, n_steps).

7. $C_p$ Model Selection¶

Mallows' $C_p$ estimates prediction risk at each step of the LARS path:

$$C_p = \frac{\text{RSS}_p}{\hat{\sigma}^2} - n + 2p$$

where $n$ is the number of training observations, $p$ is the number of active variables plus intercept, and $\hat{\sigma}^2$ is estimated from the full OLS model (last step).

In [8]:
n = len(z_train)
z_bar = z_train.mean()

# Predictions at each step: intercept = z_bar (X_s is zero-mean)
z_hat = z_bar + X_s @ path          # shape (n, n_steps)
rss = np.sum((z_train[:, None] - z_hat) ** 2, axis=0)

# Number of parameters at each step (nonzero coefficients + intercept)
p_s = (path != 0).sum(axis=0) + 1

# sigma^2 from OLS (last step)
sigma2 = rss[-1] / (n - p_s[-1])
print(f"sigma^2 = {sigma2:.4f},  sigma = {np.sqrt(sigma2):.4f}")

Cp = rss / sigma2 - n + 2 * p_s

best_step = np.argmin(Cp)
print(f"Optimal step: {best_step}  ({int(p_s[best_step]) - 1} variables,  Cp = {Cp[best_step]:.1f})")

sigma^2 = 0.4027,  sigma = 0.6345

# Analyze how R² changes as a function of Cp-selected step (model complexity)
r2_train_list = []
r2_val_list = []
num_vars = []

for step in range(path_train.shape[1]):
    coef_step = path_train[:, step]
    n_active = np.sum(coef_step != 0)
    if n_active == 0:
        # Skip degenerate model (no variables)
        r2_train_list.append(np.nan)
        r2_val_list.append(np.nan)
        num_vars.append(0)
        continue

    # Training predictions
    y_pred_train = softplus(z_bar_train + X_s_train @ coef_step)
    r2_train_list.append(r2_score(y_train, y_pred_train))

    # Validation predictions
    y_pred_val = softplus(z_bar_train + X_s_val @ coef_step)
    r2_val_list.append(r2_score(y_val, y_pred_val))
    num_vars.append(n_active)

figure(figsize=(8, 5))
plot(num_vars, r2_train_list, label='Training R²', marker='o')
plot(num_vars, r2_val_list, label='Validation R²', marker='o')

ylabel('R²')
